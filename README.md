# PLUTO-PROJECT-02-HEART-DISEASE-PREDICTION

## Project Overview

This project develops and evaluates machine learning models for predicting the presence of heart disease using patient health data. Multiple classification algorithms were trained and compared to identify the best-performing model.

## Dataset

Heart Disease Prediction Dataset

Source:
https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset

## Objectives

* Load and preprocess the dataset.
* Perform feature engineering and feature analysis.
* Train three machine learning models.
* Compare model performance using evaluation metrics.
* Select the best model and justify the choice.

## Machine Learning Models

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Random Forest Classifier

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score

## Results

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 78.69%   |
| KNN                 | 73.77%   |
| Random Forest       | 83.61%   |

## Best Model

Random Forest achieved the highest accuracy and F1 score, making it the best-performing model for heart disease prediction.

## Visualizations

* Correlation Heatmap
* Feature Importance Plot
* Confusion Matrix

## Conclusion

Random Forest outperformed Logistic Regression and KNN across all major evaluation metrics. The model demonstrated strong predictive capability and produced the fewest classification errors. Therefore, Random Forest was selected as the final model for heart disease prediction.
